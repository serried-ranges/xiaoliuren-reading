册一

上手使用

从提出问题到复盘备忘：起卦、排盘、记录、主题、AI 与数据边界。

01

先问清，再起局

一套不赶时间、适合第一次使用的顺序

1

先定一个具体问题

一次只问一件事，尽量具体、可观察，并给出关心的时间范围。例如：“未来两周，我先完善方案还是先约客户沟通？”比“我以后会怎样？”更容易理解，也更方便之后复盘。

2

问念可以留空

只想体验排盘时，可以不填问题；输入三个数仍可推算。若希望以后记得当时在想什么，建议写一句简洁问念。不要放入与问题无关的隐私或他人敏感信息。

3

选一种取数方式

初次使用可手动输入三个数，或点“时间起卦”按所选农历月日时填入数值。先看一眼三个数字，再点击“开始推算”。快捷按钮只填数，不会直接排盘。不必为了“选到好结果”连续起多次；先记录当下判断。

关于“不建议上来就随机数”

随机数只是由浏览器生成数字，不是更客观或更准确的途径。反复随机后只挑喜欢的结果，容易产生选择性解读。

没有合适的取数来源时，随机数可以用于练习；建议先明确问题，再起一次并保留记录。

02

起卦前的四个提醒

把问题、方法与记录照顾好，比反复求一个答案更重要

01

一课一问

把一个关心点说清楚，并限定时间范围；多件事分开记录，减少事后混读。

02

先定取数法

手动、时间、随机是不同输入来源。选一种适合自己的方式，避免同一问题连续重抽。

03

留下原始记录

记下当时的问题、三数与自己的判断。不要只保存后来挑中的结果，复盘才有上下文。

04

保护自己与他人

问念无需写姓名、证件、病历等无关敏感资料；涉及他人时，只描述自己关心的现实处境。

把它当作整理思路的工具

盘面和解读属于传统文化体验，不是经过科学验证的确定性预测。不要让一次结果替代证据、沟通和专业建议。

医疗、法律、投资、工作安全等重大决定，应优先依据事实并咨询相应专业人士。

03

取数与起卦方式

在「更多」切换起课体系；输入区再选江氏方法与起卦时间，三数与两步分别计算

两种起课体系

在「更多 → 江氏起课」切换：关闭为三数起卦，开启为江氏起课。三数保留手动、时间和随机取数；江氏在输入区选择报数、日时或时刻，重置按钮位于方法行。切换会清空当前输入与结果，保留上次江氏方法和历史记录，不会自动排盘或调用 AI。

手动输入

三数输入范围为 1–999 的整数；小数、负数和越界值不会被自动改成别的数。

适合自己已有取数习惯，或固定一组数做练习。

手动输入会被记录为“手动输入”方式。

三数时间起卦

先在输入区选择“当前时间”或“指定时间”，再点击“时间起卦”。程序按所选本地日期，将农历月、农历日、时辰序号依次填入三数（子时记 1……亥时记 12）。

指定时间后会显示农历与时辰；手动或随机起卦不改三数，只采用该时间作为排盘背景。修改时间后需点击“开始推算”或“重新推算”，不会自动解读，也不会改写旧卦例。重置、切换身份或刷新页面后恢复当前时间。

确认问念、数字，再按“开始推算”。即使跨过时辰或午夜，仍使用点击取数时的时间；手动改数后转为手动输入。

按设备当地时间，00:00 换日，23:00 不提前换日；闰月沿用同名月数。支持 1900-01-31 至 2100-12-31；旧时钟取数入口已移除，旧记录保留原结果。

随机起卦

点击后由浏览器随机接口生成三个 1–999 的数值。

适合演示或练习；它不比手动或时间取数更准确。

同一问题避免不断重抽、挑选结果。

江氏报数

选择“江氏报数”，输入一个 1–200 位正整数，再点击开始推算。报数除六取余起宫，整除时取六；从报数宫起时辰，不拆成三数。也可先按自己确认的笔画口径把心中汉字换算为数字再输入；程序不会自动识别汉字笔画。

例如 333、申时：报数宫速喜 → 身宫小吉。

江氏日时

按当前或指定时间取农历日与时辰。大安上起日、日宫上起时；月份仅作背景，不参与计数。

例如初三、辰时：日宫速喜 → 身宫大安。

江氏时刻

从大安起时辰，再从时宫起十分钟刻。每时辰十二刻；子时从23:00开始，00:00为第七刻。

例如11:25：午时落大安 → 寅刻落速喜。不是旧的小时加分钟取数。

推荐顺序

写清一个问题 → 手动取数或时间起卦 → 核对输入 → 开始推算 → 记录自己的判断。

“随机起卦”是可选项，不是首次使用的必经步骤；页面不会替你判断哪种方法更灵验。

例：农历三月初五辰时取 3、5、5，依次为速喜 → 大安 → 小吉。旧时钟拆数习惯仍可通过手动输入练习，不另设快捷入口。

05

记录、复盘与备份

把当下的想法留下，也给未来的自己留一份凭据

查找与回看

点页眉“记录”打开卦例。搜索可按问念、宫位结果、数字与起卦方式查找。

点击“载入”回看保存的取数、方法、结果与原时辰，不按当前时间重算，也不新增卦例。旧时间取数记录标注为“时间起卦（旧记录）”；旧江氏记录保留原装盘算法，不静默改写。

复盘反馈

在记录中打开复盘，可设置状态、标签、星级、实际结果和笔记。预设标签共 14 个，也可自定义。

复盘帮助比较“当时怎么判断”与“之后发生什么”，不等于系统验证预测准确。

导出与导入

更多 → 导出卦例：下载只包含卦例记录的 JSON 备份。

更多 → 导入卦例：先预览格式、数量、重复和冲突，再确认合并；旧版模板字段会被忽略。导入前先备份当前记录。

农历、时辰与取数规则随卦例备份保留；API Key 等接口凭据不随备份导出。问念、反馈可能含个人信息，分享前请自行检查。

本机存储需要主动备份

卦例数量上限为 999 条，实际可保存量也受浏览器存储配额影响。清理站点数据、换设备或使用不同站点地址，可能导致本地记录无法继续访问。

重要记录定期导出到你自己保管的位置；不要把同一台共享设备上的本地数据当成私密账号空间。

隐私与数据

一页看懂：数据留在哪里、什么时候离开浏览器

这一章就是公开的隐私说明

记住一句话——普通排盘与记录留在当前浏览器；主动发起模型解读时，问念与排盘摘要才会发送到接口。一键解卦、重解、风格对比和差异研判均属于模型调用，提示词预览与复制不属于。下面分开说明本机数据、请求与 Key。

本机身份与记录

应用不要求登录；历史记录按当前浏览器里的本地身份分区，不会自动同步到其他设备。

身份标识不是账号或安全认证；同一浏览器的其他使用者仍可能接触本地数据。

清理站点数据、换设备或站点地址改变，可能导致记录无法继续访问。

AI 请求会发送什么

点击一键解卦后，问念与结构化排盘摘要会发送给所选模型接口：自备 Key 时直连你填写的地址。

未配置 Key 且站点服务开启、额度可用时，请求经本站代理转发。次数受本机身份与网络 IP 限制，以解卦页面显示为准，按 UTC+8 每天 00:00 重置；额度计数不保存问念与输出。

Key 保存方式

默认“记住在本机”：按当前身份存入浏览器 localStorage，下次打开可直接使用。

当前界面不提供“仅本次使用”开关；关闭标签页不会清除已保存的 Key。共享设备不建议保存，用毕请在“更多 → 智能解读”清空 Key 并保存。

Key 不放进卦例备份。自备 Key 随请求发送给你填写的接口，请确认地址可信；站点免费调用无需你的 Key。停止使用时可在智能解读设置中清除并保存。

数据保护小建议

重要记录定期导出到自己保管的位置；公共设备不要持久保存 Key。AI 解读仅作参考，不替代专业意见。

大安

青龙 · 木 · 东方 · 谋事数 1·5·7

大安事事昌（通书常见起句）

常见象意是安定、守成与停留。结合问题区分“稳定”与“进展慢”，不直接套作凡事顺利。

留连

玄武 · 水 · 北方 · 谋事数 2·8·10

留连事难成（通书常见起句）

常见象意是延迟、牵连与反复。学习时先找文本中如何解释过程，不把它直接判作失败；道传五行与六神另有配置。

速喜

朱雀 · 火 · 南方 · 谋事数 3·6·9

速喜喜来临（通书常见起句）

常见象意是消息、快速变化与喜庆。快不等于稳，也不能仅凭名称推定事情已经发生。

赤口

赤口主口舌（通书常见起句）

常见象意是争执、分歧与沟通摩擦。只用于理解传统文本，不据此断定疾病、灾祸或他人恶意。

小吉

六合 · 木 · 和合 · 谋事数 1·5·7

小吉最吉昌（通书常见起句）

常见象意是协作、小成与流动。通书版本有木、水等异文；不要把这套属性直接代入道传或江氏盘。

空亡

常见象意是信息缺失、期待落空与尚未落实。保留“不确定”的空间，不以旧断辞恐吓读者。

“类象”是传统文本用于组织联想的词汇。先核对体系与问题，再把象意写成可以讨论的假设；颜色、神名或一个宫名都不能单独证明现实状况。

起课与断卦入门

传统时间法起课三步、断卦四步与体用速记

起课三步（传统时间法） A 级

① 起月：大安起正月，顺数到所求月份 → 月宫（大环境）。

② 起日：从月宫起初一，顺数到所求日辰 → 日宫（过程 / 对方）。

③ 起时：从日宫起子时，顺数到所求时辰 → 时宫（结果 / 自身）。

每一步都把起点记为 1，不先跳下一宫。三月初五辰时可写为 3、5、5，三宫为速喜 → 大安 → 小吉。江氏报数、日时、时刻需从起卦方式中另选，采用两步起课；外应未设独立入口，可按已知取数手动练习。

断读四步（按所选体系）

① 定吉凶：先看最终落宫（时宫）的吉凶属性。

② 看三宫：月＝大环境 / 起因，日＝过程 / 客体，时＝结果 / 主体。

③ 查规则：道传可看体用与三宫关系；江氏先核对装卦，再取用神。不要把不同体系的步骤拼成一个通用算法。

④ 留待复盘：将象意写成有条件的解释，记录不确定处，再与现实反馈核对，不把数应直接当作精确日期。

五行生克

传统象意的比较语言，不是现实事物间的物理作用或结果保证。“体”和“用”先确定属于哪套读法，再比较五行。

日宫与时宫数学上有 6 × 6＝36 种组合，不等于已核到 36 条通行口诀。资料缺文时保留空缺，不用推测补成“古诀”。

相生：木生火 → 火生土 → 土生金 → 金生水 → 水生木。

相克：金克木 → 木克土 → 土克水 → 水克火 → 火克金。

遇事即占、无事勿占；一事一占、初占为准；同一事不重占、不因结果不好而换时辰再占；不戏占、不占赌博与国运政治。

古法 / 江氏 / 道传 对照

同一套六宫，三系读法不同；并列记录、不混用

先厘清名号 B 级

下表比较公开资料的规则，不代表本程序提供全部取课方式。三数／农历月日时沿用兼容三宫；江氏报数／日时／时刻单独采用两步课。两类方法并存，不把农历月日时冒称为江氏日时法。

在本册所引的邵一尘系资料中，“道传”与“道家小六壬”两名并用；江氏的装卦与取用规则另成体系。名称相近不等于算法相同，也不能把所有带“道家”字样的资料都归入邵系。

对比项传统（玉匣记 / 马前课）道传 · 道家（邵系）江氏（江春义系）
结构三宫（月/日/时），落宫直断三宫＝天/地/人；落宫为体、时辰为用六宫全装：地支＋六亲＋六神＋五星
起课月日时月日时（亦可用报数 / 外应）日时／时刻／数字（不用月）
断法口诀直断象意＋体用＋转太极＋具象取用神（六亲宫）＋生克旺衰，一课多断
文献《玉匣记》七篇＋《卜法浅要通则》＋十二卷叙述公开教程与作者案例；整理索引不代表逐案验证

资料读法与当前实现

新江氏盘以最终身宫安身支，顺排隔位地支：报数、日时用起课时支，时刻法用刻支；青龙随身支起宫，六星从起宫顺排。本项目“天星”对应教程“天空”。身支非土时，顺宫遇到的第一个土支作“兄弟”，地支五行仍为土。

两步课从报数宫／日宫／时宫起木星；三数扩展以第三宫为“自身”、第二数宫起木星，并另取起卦时辰装盘，不冒称标准日时法。旧记录按保存版本保留原盘，推算过程说明旧口径，不因升级静默改变。规则可复算，不代表预测准确率已经验证，也不包含转太极等全部断法。

道传资料内部及其与程序之间也有六神配属差异，尤其留连、空亡。操作时看当前盘面，研习时注明版本；发现不同先核对取数、起点与配属，不用另一张表覆盖原盘。

本项目以人宫的宫五行为体，以起课时辰的地支五行为用。宫五行与地支五行分别列示，不互相替代；只计算五类生克关系，未计算阴阳比助／比劫、旺衰或具体应期。体用是辅助依据，不单独决定吉凶。

分歧最重的地方：五行与六神

通书版：大安木青龙、留连水玄武、速喜火朱雀、赤口金白虎、小吉木六合、空亡土勾陈。

道传版：留连作“四方土·腾蛇”、小吉作“水·玄武”，自称“四方四季＋中央”之理。

江氏体系重心在“地支装卦”，六宫五行权重较低。三家数字也互不通用——本册并列记录，不裁定谁对。

同一课、不同读法

若三宫落“速喜 → 速喜 → 空亡”：传统读法直接套落宫口诀；道传读法看三宫成象与体用；江氏则先装地支、六亲、六神、五星，再取用神看其所临宫与神。结论：同一“卦”，三系给出的信息层完全不同，这正是“不能混用”的原因。

阅读建议

给每篇文章先“贴标签”：属于传统 / 道传 / 江氏 / 其他，再看其五行、数字、起课是否与所选框一致。

想快断吉凶看传统口诀；想细断来龙去脉看道传；想一事多断、关系网清晰看江氏。不东拼西凑。

项目初心与设计取舍

让工具服务于思考，而不是把判断变成必须购买的答案

起点：先把工具做出来

项目最初只是一次“把排盘放到浏览器里”的尝试。没有先做账号、后台或复杂部署，而是先验证一件事：历法和排盘能不能算对。这个起点决定了后来的取向——先保证核心正确，再谈界面、扩展和发布。

工具负责计算、整理和呈现；是否起卦、如何理解、下一步怎么做，始终交给使用者。

转折一 · 能算对从“能运行”到“按规则计算”：接入历法库，补上八字、节气与道传排盘，把算法层和显示层分开，用测试核对计算与视图切换。
转折二 · 一个发布源曾并行维护多个版本并探索 Serverless 与 App 验证线，重复实现与文档漂移让维护成本上升；后来旧版与小红书版独立维护，本项目聚焦 V3，同一源码构建完整发布包。
转折三 · 有边界的发布从本地工具走向公开发布，先明确基础功能平等、AI 按需使用，最初由用户自备 Key，后来补充有限免费体验。服务可以扩展，数据去向与使用边界始终要说清楚。

核心理念

先把计算做对，再做好看：先验证历法、三数取余和排盘规则，再谈交互与视觉；计算结果可测试，不等于预测结论可信。

基础功能平等：排盘、记录、主题、导入导出、提示词生成与复制都不设付费门槛，也不因是否填写 Key 而分层。

删繁就简 · 同源优先：能删的入口就删；古法、江氏、道传共用同一组三数与同一条卦例，汇总与一键解卦共用同一份综合提示词构造器，避免规则漂移。

模块化 · 重测试：主题、交互与视图、排盘核心、AI 分层；核心规则与关键操作有回归检查，功能现状以源码和验收结果为依据。

站点在服务开启且额度可用时提供有限免费解读，让未填写 Key 的人也能体验。这是“能帮一点是一点”的心意，不是永久服务或预测承诺，也不改变基础功能平等。
