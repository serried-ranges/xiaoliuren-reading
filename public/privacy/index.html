隐私边界

用最短的话说明数据留在哪里、什么时候离开浏览器。

适用版本：V3.0.0 · 资料站校对：2026-09-20

先说结论：普通排盘和历史记录优先在当前浏览器完成；只有你主动使用一键解卦时，必要数据才会发送到你填写的模型接口。

留在浏览器

  • 页面不要求注册，也不申请麦克风、通讯录、定位等设备权限。
  • 主题、界面偏好、身份标识和历史记录保存在当前浏览器，不会自动跨设备同步。
  • 清理站点数据、共享设备或浏览器故障可能造成记录丢失；重要记录请导出 JSON 备份。

主动使用 AI

  • “AI 提示词”只在本机生成、检查和复制，不会自动调用模型。
  • “一键解卦”由你主动发起；问念、排盘摘要和认证信息会交给你配置的服务商处理。
  • API Key 只应在浏览器中填写，不要放入仓库、截图、导出文件或公开反馈。

公开页面

资料页可能被缓存、下载或镜像。请不要在公开页面、截图和反馈中提交 API Key、身份证明或其他敏感资料。

普通排盘属于民俗文化体验与学习参考，不替代医疗、法律、财务等专业意见。
