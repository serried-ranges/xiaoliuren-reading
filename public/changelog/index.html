2026-09-21 · 未填 Key 也能一键解卦（免费额度代理）

未填写自己的 API Key 时，「一键解卦」可经本站的 Cloudflare 受控代理转发到模型服务：项目方 Key 只保存在服务端，不会下发到浏览器。免费额度按 UTC+8 每天 00:00 重置，每个本机身份 10 次、每个网络 20 次；代理只做每日额度计数，不记录问念、排盘摘要或解读内容。填写自己的 Key 仍是直连你自己的接口、不限次数。

2026-09-21 · 本地 Key 保存说明与静态页跳转修正

明确 API Key 默认保存在当前浏览器、当前身份，保存后无需重复填写，且不会上传到本项目服务器；同步更新隐私说明，并保留临时模式的清除提示。修正资料页与应用内项目说明、鸣谢名单的本地/线上跳转逻辑，方便本地调试与线上访问保持一致。
