2026-09-28 · 智能解读与使用体验优化

智能解读：优化网络异常、等待超时和服务繁忙时的提示，明确说明本次请求的免费次数处理情况；调整风格选项文字对齐，让操作状态更清晰。

玑衡添筹令：调整次数补充规则，每次增加 5 次，每日最多兑换 3 次；当日累计输错 3 次后暂停兑换，减少误操作与滥用。

主题与标志：未手动选择主题时，浅色模式默认使用暖金，深色模式默认使用玄夜；手动选择后保留你的偏好。优化深色主题下的太极图配色，让标志更清晰易辨。

2026-09-27 · 排盘与解读体验优化

一键解卦：新增古法、江氏与道传合参解读；可使用自备 API Key，或在站点额度启用时使用项目额度，结果保存到当前卦例。

排盘与首页：江氏排盘支持表格／六宫图切换，并优化六宫图比例、字级与五行配色，排盘规则不变。首页静心词支持轻点轮换、双击随机、长按选择。

记录与资料：本地卦例上限由 200 条提升至 999 条，并完善容量提示、存储告警与备份校验；精简项目说明文案，统一资料卡片布局。记录仅保存在当前设备，实际容量受浏览器空间限制，建议定期备份。

2026-09-22 · 新增「获取 DeepSeek API Key」教程

在项目说明页新增「获取 DeepSeek API Key」入口，并新增教程页 /guide/deepseek-key/：按注册账号、实名认证、充值额度、创建 API Key、回到应用填写五步说明「一键解卦」的前置条件，并给出安全提醒、费用边界与常见问题。不填写 Key 时，排盘、记录与 AI 提示词仍可正常使用。

2026-09-21 · 本地 Key 保存说明与静态页跳转修正

明确 API Key 默认保存在当前浏览器、当前身份，保存后无需重复填写，且不会上传到本项目服务器；同步更新隐私说明，并保留临时模式的清除提示。修正资料页与应用内项目说明、鸣谢名单的本地/线上跳转逻辑，方便本地调试与线上访问保持一致。
