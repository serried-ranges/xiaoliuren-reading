项目说明

玑衡小六壬排盘是一款无须注册的民俗文化体验工具。排盘、记录与复盘在浏览器中完成，AI 解读按需使用，把判断留给自己。

第一次来，从这里开始

  • ① 开始排盘：点上方「排盘应用」，选择手动、时间或随机取数，确认数字后点击“开始推算”。
  • ② 了解操作：从阅读手册的上手部分开始；想学习术语与体系，可看研习速览。
  • ③ 按需解读：了解AI 提示词与一键解卦的区别，再选择是否调用模型。

记录保存在当前浏览器，不自动跨设备同步；重要内容请定期导出备份。

设计取向

  • 本地优先：普通排盘、主题偏好和历史记录先在当前浏览器完成，不要求登录，也不自动跨设备同步。
  • 主动选择：AI 提示词在本机生成、检查与复制，不调用模型。一键解卦、重解、追问和风格对比等主动操作，会向模型接口发送问念与必要的排盘信息。
  • 两种调用：自备 API Key 时直连你填写的接口；未填写时，站点开启免费服务且额度可用，才能使用项目额度。可用次数以解卦页面显示为准，自备 Key 的费用与限额由服务商决定。
  • 数据说明：数据去向、Key 保存与免费额度规则见阅读手册 · 隐私与数据。
